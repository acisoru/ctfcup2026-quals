# GhostVector | pwn, reverse, hardware

**Автор:** [@pipeline_sh](https://t.me/pipeline_sh) · [GitHub](https://github.com/f0rtis-net)

## Описание

На стенде остался один RISC-V узел от экспериментального кластера. Обычная телеметрия утверждает, что всё штатно: пользователь изолирован, память защищена, а секреты недоступны.

Но инженеры почему-то оставили в образе диагностический интерфейс для «ускорителя векторных вычислений». Говорят, он нужен лишь для калибровки и никак не участвует в модели безопасности.

Образ минималистичен, но не пуст: иногда самый полезный инструмент уже лежит рядом с устройством, которое он проверяет. И не всякое движение данных происходит через обычные инструкции процессора. Некоторые следы калибровки удобнее изучать вне самого узла.
