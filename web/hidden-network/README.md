# Hidden Network | web, protocol, lte

**Автор:** [@pipeline_sh](https://t.me/pipeline_sh) · [GitHub](https://github.com/f0rtis-net)

## Описание

После неудачного обновления прошивки одна из малых сот начала помнить больше, чем ей положено. Панель обслуживания уверяет, что всё работает штатно, но в закрытом контуре сети всё ещё живут следы старых сессий.
Найдите путь от внешней консоли до этого «эха» и выясните, почему чужой служебный шёпот иногда звучит для сети убедительнее голоса его владельца.

_Внимание: запуск инстанса может занимать несколько минут._
