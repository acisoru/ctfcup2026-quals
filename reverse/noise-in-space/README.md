# Noise in space | dsp, reverse

**Автор:** [@pipeline_sh](https://t.me/pipeline_sh) · [GitHub](https://github.com/f0rtis-net)

## Описание

В опечатанном подвале ликвидированной станции «Горизонт-12» нашли аппарат, которого не было ни в одной описи. На передней панели — выгоревшая шкала, гнездо сервисного терминала и единственная надпись, процарапанная уже после
эвакуации:

        НЕ ДОВЕРЯЙ НУЛЮ. ОН СЛИШКОМ УДОБНЫЙ.

Рядом лежали дамп и сервисный kernel. Судя по журналу, после последнего обновления приёмник исправно обрабатывал запись целиком, рисовал правильную форму волны и выдавал звук — только дежурные слышали вместо сообщения нечто, похожее на разговор, который ведут за стеной из вращающегося стекла.
