# My Own FS — разбор

## 1. Формат ФС

Из `myfs/src/main.rs`:

```text
N = размер_образа / 1338

[0, N)                        список инодов: 1 байт на инод, 0 = свободен, 1 = занят
[N + i*1337, N + (i+1)*1337)  инод i
```

Головной (первый) инод файла, заголовок 51 байт:

| смещение | тип | поле |
|---|---|---|
| 0  | u32 | next — следующий инод файла, 0 = конец |
| 4  | u8  | тип: 1 = файл, 2 = каталог |
| 5  | u16 | mode |
| 7  | u32 | uid |
| 11 | u32 | gid |
| 15 | u64 | size |
| 23 | i64 | atime |
| 31 | i64 | mtime |
| 39 | i64 | ctime |
| 47 | u32 | nlink |
| 51 | …   | данные (1286 байт) |

Продолжение: `u32 next`, `u8 тип = 0`, далее 1332 байта данных.
Каталог — это файл из записей `u32 инод, u8 длина имени, имя`. Инод 0 — корень.

## 2. Что видно сразу

```console
$ cargo build --release && mkdir mnt && ./target/release/myfs mount disk.img mnt &
$ ls mnt
README.txt  todo.txt
```

Все каталоги удалены. Почти весь образ помечен свободным, но в `unlink`/`rmdir` и
`write_data` освобождение — это только запись 0 в список инодов (`Disk::mark`),
содержимое инодов, включая указатели `next`, остаётся на месте.

Записи удалённых каталогов при этом тоже пропадают: `rm -rf` сначала удаляет файлы,
и каждый `unlink` переписывает каталог без удалённой записи. Так что имя `flag.png`
искать бесполезно, искать нужно по содержимому.

## 3. Восстановление

Иноды были перемешаны (`myfs shuffle`), поэтому цепочка файла разбросана по образу,
и сигнатуру PNG с последующим чтением подряд использовать нельзя. Но указатели
`next` при перемешивании переписаны корректно, значит достаточно:

1. перебрать все иноды и найти тот, у которого тип 1 и данные (смещение 51)
   начинаются с `\x89PNG\r\n\x1a\n`;
2. взять `size` со смещения 15;
3. идти по `next`, собирая данные (51 байт заголовка у первого инода, 5 — у остальных),
   и обрезать результат до `size`.

```console
$ python3 solve.py disk.img
inode 2979 (used=0): 214153 bytes -> carved_2979.png
```

На картинке — флаг:

```text
ctfcup{dbf75e112fef01db44b2a0e68ab2065e}
```

Номер инода меняется от генерации к генерации.
