## Идея

Задача на реверс передатчика. Флаг с CRC32 передаётся четырьмя видами. Формат записи: WAV, моно, 48 кГц, PCM 16 бит; один символ занимает 2048 сэмплов.
Данные защищены кодом Рида–Соломона RS(7,3) над GF(8), исправляющим до двух ошибок на блок из семи символов. Дифференциальная фаза маскируется выходом линейного генератора с состоянием 128 бит. Амплитуда сигнала - 0,35, шум - примерно ±0,015.

## Решение

Восстановить протокол из бинарного файла. Корреляцией с четырьмя шаблонами определить вид чирпа и его полярность, затем декодировать RS(7,3). Полученные метки раскрывают два выхода генератора на каждый бит сообщения.

Составить систему линейных уравнений над GF(2): первые 64 логических символа дают ранг 128 и позволяют восстановить начальное состояние. Затем воспроизвести скрытые выходы генератора, снять маску и дифференциальное кодирование, проверить CRC32.

Готовый решатель: [solve/solve.py](solve/solve.py). Подробный разбор с графиками: [solve/WRITEUP.md](solve/WRITEUP.md)
