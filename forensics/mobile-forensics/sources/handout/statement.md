# Burnt Note

Mobile Forensics / Android · Hard++

Изъят телефон курьера сети закладок. Переписка велась в Burnt Note с
самоуничтожающимися сообщениями. После тотальной чистки таблица сообщений
пуста, а сервер `sync.burntnote.onion` недоступен.

Восстановите последнее сообщение переписки и найдите в нём контрольную фразу.

## Файлы

```text
evidence.tar.gz — forensic-образ устройства
burntnote.apk   — APK Burnt Note для реверса
```

## Ожидаемый результат

Найдите четыре seed-фрагмента в артефактах телефона, восстановите порядок по
UTC, выведите ключ из APK, затем восстановите и расшифруйте цепочку сообщений.
Таблица SQLite после очистки неполна: часть строк находится в freelist и
freeblock-остатках, остальные — в повреждённом WAL.

Флаг находится в последнем сообщении.
