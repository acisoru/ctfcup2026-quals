# Райтап: snake (ppc)

Флаг: `ctfcup{23cdba78b236aa2e478d0d562d34562c_%s}`

## 0. Дано

Змейка на шестиугольном поле из сот со стороной 5 клеток (61 клетка).
Сервер на Go, фронтенд встроен. Всё общение - по websocket `/ws`:

- после подключения сервер присылает состояние;
- клиент шлёт `{"type":"move","dir":N}` (`N` от 0 до 5: E, NE, NW, W, SW, SE в
  осевых координатах `q, r`) или `{"type":"reset"}`;
- в ответ на каждое сообщение приходит состояние:
  `snake` (голова первая), `food`, `length`, `target`, `alive`, `won`, и при
  `won` - `message` с флагом.

Таймера нет, змейка ходит только по сообщению. Выигрыш - длина 61, то есть
змейка должна занять всё поле. Стенка и собственное тело убивают, при этом
на клетку хвоста наступать можно (хвост уезжает на этом же ходу).

## 1. Почему не руками

До выигрыша нужно съесть 60 единиц еды, которые появляются в случайных
свободных клетках, не умерев ни разу. На шестиугольной сетке с шестью
направлениями это нереально, но ходы можно отправлять скриптом: протокол
виден во вкладке Network или прямо в исходниках страницы.

## 2. Гамильтонов цикл

Самый простой безопасный бот ездит по гамильтонову циклу: если змейка всегда
двигается вдоль замкнутого пути через все клетки, она никогда не врежется в
себя и рано или поздно съест всё.

Строим цикл в осевых координатах `(q, r)`, `|q|, |r|, |q+r| <= 4`:

1. Ряды `r = -4..2` обходим «змейкой» (чётные - на восток, нечётные - на
   запад), пропуская самую западную клетку каждого ряда.
2. Ряды 3 и 4 проходим вертикальным зигзагом:
   `(1,3) (0,4) (0,3) (-1,3) (-1,4) (-2,4) (-2,3) (-3,3) (-3,4) (-4,4)`.
3. Западные клетки рядов `r = 3..-4` образуют связный столбец
   `(-4,3) ... (-4,0) (-3,-1) (-2,-2) (-1,-3) (0,-4)` - по нему
   возвращаемся наверх к стартовой клетке `(1,-4)`.

Итого 43 + 10 + 8 = 61 клетка, соседство каждой пары проверяется
`assert`-ом в скрипте.

## 3. Срезки

Полный цикл даёт до 60 ходов на единицу еды, то есть несколько тысяч ходов.
Ускоряем: пока змейка ходит только вперёд по циклу, её тело лежит на дуге
цикла позади головы. Значит любая клетка, которая по ходу цикла ближе к голове,
чем хвост, гарантированно свободна. На каждом шаге из шести соседей головы
берём самого далёкого по циклу при условиях:

- расстояние по циклу до него не больше расстояния до хвоста (сам хвост
  уезжает на этом ходу, на него наступать можно);
- он не дальше еды (иначе перепрыгнем её и придётся делать круг).

Инвариант сохраняется после каждого такого хода, поэтому бот не умирает, а
заполняет поле примерно за тысячу ходов.

## 4. Запуск

```
pip install websocket-client
./solve.py http://<token>.<host>
```

Скрипт печатает флаг из поля `message` в последнем состоянии.
