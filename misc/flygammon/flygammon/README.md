# flygammon

CTF-задача (medium-hard): обыграть «мозг мухи», играющий в нарды на блокчейне.

## Легенда

Лига нард `GENL`, где вместо людей играют эмулированные коннектомы дрозофилы
(`FruitFlyOracle`). Модель позиционируется как непобедимая нейросеть, дистиллированная
из 140k синапсов FlyWire. Участнику выдаётся инстанс блокчейна, стартовый баланс
токенов и задача выиграть матч у роя мух — после чего чекер отдаёт флаг.

## Суть (для авторов, не для игроков)

- Контракты **честные**. Блокчейн — неподкупный судья: кости честные (VRF /
  commit-reveal), инференс детерминированный. Выиграть «повезло» нельзя.
- Муха — **по-настоящему сильная** модель в стиле TD-Gammon. Честная игра против
  неё не даёт стабильной победы.
- У модели есть **точечное слепое пятно**, встроенное через урезанное кодирование
  входа: она не «видит» угрозу closeout / чужого прайма. Единственный надёжный путь
  к победе — вскрыть эту зону реверсом весов (sensitivity-пробинг), загнать муху в
  closeout-ловушку и снять фишки.
- Тематический якорь: реальная adversarial-атака на суперчеловеческий Go-ИИ KataGo
  (Wang et al., 2023) — победа не силой, а «странностью». Предок — TD-Gammon
  (Tesauro, 1992).

## Что реверсит игрок

Файл весов + необходимость восстановить **функцию кодирования признаков**. Слепая
зона спрятана именно в кодировании. Формат — сырой бинарь / самодельный, не готовый
ONNX с именами слоёв.

## Компоненты

| Компонент        | Роль                                                        |
|------------------|-------------------------------------------------------------|
| движок нард      | генерация/легальность ходов, удары, bear-off, скоринг       |
| энкодер признаков| кодирование доски в вектор входа (**с закладкой**)          |
| модель мухи      | небольшая сеть TD-Gammon-типа, детерминированный 1-ply выбор|
| тренер           | TD(λ) self-play ИЛИ дистилляция из сильного движка          |
| экспортёр        | квантизация int8 + сериализация в формат артефакта          |
| reference solver | локальный симулятор + поиск closeout-линии = эталонное решение |

## Открытые калибровки

- Сила урезания кодирования ↔ винрейт closeout-эксплойта (цель ≈ ≥90%).
- N очков в матче для условия победы (гасит дисперсию костей).
